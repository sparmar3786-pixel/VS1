# VS1 Trading APK

Mobile-first VS1 trading terminal based on the requested Grok Workspace design.

- 40 interactive tabs
- AI 6-Layer
- Watchlist, Signals, Option Chain Pro, Research Hub, Scanner Pro
- Angel One API and NSE MCP integration readiness panels
- Capacitor Android wrapper
- GitHub Actions debug APK build

Live Angel One trading and NSE MCP data require a separately deployed backend and secrets. Never embed API keys, PINs or TOTP secrets in the APK.
